01 DNS Resolution

Using nslookup in Windows PowerShell to resolve the GitHub Pages domain.

PowerShell — nslookup DNS 
PS C:\> nslookup awright136.github.io

Server:  UnKnown
Address: 192.168.1.1

Non-authoritative answer:
Name:    awright136.github.io
Addresses: 2606:50c0:8000::153   ← IPv6
           2606:50c0:8001::153
           2606:50c0:8002::153
           2606:50c0:8003::153
           185.199.108.153        ← IPv4
           185.199.109.153
           185.199.110.153
           185.199.111.153

Analysis

The DNS query returns both A records (IPv4) and AAAA records (IPv6), confirming GitHub Pages' dual-stack support. The four IPv4 addresses are load-balanced across GitHub's CDN infrastructure. The non-authoritative response means our local resolver cached the answer from GitHub's authoritative nameservers.

02 IPv4 vs IPv6

Both protocol versions are supported. GitHub Pages infrastructure is fully dual-stack.

IPv4
185.199.108.153

32-bit address · ~4.3 billion possible addresses · Still dominant on the web

IPv6
2606:50c0:8000::153

128-bit address · 340 undecillion addresses · Future-proof, no NAT needed

PowerShell — Ping IPv4 vs IPv6 ICMP 
PS C:\> ping -4 awright136.github.io
Reply from 185.199.108.153: bytes=32 time=18ms TTL=57

PS C:\> ping -6 awright136.github.io
Reply from 2606:50c0:8000::153: bytes=32 time=19ms TTL=57

03 HTTP vs HTTPS Headers

Using curl.exe to compare headers on plain HTTP vs encrypted HTTPS responses.

curl — HTTP (Port 80) Insecure 
PS C:\> curl.exe -I http://awright136.github.io/cn-project1/

HTTP/1.1 301 Moved Permanently
Location: https://awright136.github.io/cn-project1/
X-GitHub-Request-Id: ...

HTTP Result

HTTP returns a 301 redirect to HTTPS immediately — GitHub Pages enforces HTTPS for all traffic. Plain HTTP is never served. This is the correct behavior.

curl — HTTPS (Port 443 + TLS) Secure 
PS C:\> curl.exe -I https://awright136.github.io/cn-project1/

HTTP/2 200
content-type: text/html; charset=utf-8
strict-transport-security: max-age=31557600
x-content-type-options: nosniff
x-frame-options: deny
x-xss-protection: 1; mode=block
content-security-policy: default-src 'self'; ...
cache-control: max-age=600
x-github-request-id: ...

HTTPS Result

The HTTPS response returns HTTP/2 (more efficient than HTTP/1.1), includes HSTS (Strict-Transport-Security) forcing all future requests to use HTTPS, and our added security headers (X-Frame-Options, CSP, X-Content-Type-Options).
