03 Project Comparison

What changed from Project 1 to Project 2:

Feature Project 1 Project 2
HTTPS Basic (no custom headers) ✓ HSTS + full header suite
Content Security Policy None ✓ Strict CSP implemented
XSS Protection None ✓ Input sanitization + X-XSS header
Contact Form None ✓ With honeypot + validation
Performance Caching None ✓ 7-day cache for static assets
Image Loading Eager (blocks render) ✓ Lazy load via IntersectionObserver
Security Audit Not performed ✓ A+ on Mozilla Observatory
Wireshark Analysis Not performed ✓ TLSv1.3 verified

04 Deployment Steps

  1. 1
    Forked / updated the existing cn-project1 repository

    All new Project 2 files were added to the same repo to keep the live URL unchanged.

  2. 2
    Added _headers file to repo root

    Enforces security and cache-control headers at the CDN level on every response.

  3. 3
    Verified HTTPS enforcement in GitHub Pages settings

    "Enforce HTTPS" checkbox enabled → all HTTP redirects to HTTPS automatically.

  4. 4
    Ran Mozilla Observatory scan

    Confirmed A+ score. Adjusted CSP directives based on scan recommendations.

  5. 5
    Ran Wireshark capture to verify TLS

    Confirmed all traffic uses TLSv1.3 and no plaintext data is transmitted.
