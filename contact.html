How the Security Works

Honeypot field

A hidden text input (name="website") is placed off-screen using CSS (position: absolute; left: -9999px). Real users never see or fill it. Bots that auto-fill all fields trigger it — the form is silently rejected without alerting the bot.

XSS Sanitization

Before any input is processed, all <, >, &, and " characters are escaped to their HTML entity equivalents. This prevents injected HTML/JavaScript from executing in the browser.

Client-side Rate Limit

A timestamp check prevents re-submission within 10 seconds, discouraging spam bursts from the same session. A real backend would enforce this server-side with express-rate-limit.
